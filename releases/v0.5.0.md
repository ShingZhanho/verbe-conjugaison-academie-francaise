This release corrects the parser defects identified by the complete manual audit of v0.4.0 and adds a lexical elision/liaison blocking flag. It uses the already validated local artifacts rebuilt from cached Académie française HTML on 2026-10-29; it does not incorporate a new website crawl.

### Breaking changes and migration

- **Gendered passive present participles:** for `devoir` and `redevoir`, JSON `voix_passive.participe.present` changes from a string (for example, `"étant dus, dues"`) to an object with `sm`, `sf`, `pm`, `pf`. In SQLite, their generic `forme = 'present'` row is replaced by `present_sm`, `present_sf`, `present_pm`, `present_pf`. Update consumers that expect the former string or generic row; this matches the representation already used for other agreeing passive participles.
- **Additional metadata:** every JSON entry gains boolean `bloque_elision_liaison`, and the SQLite `verbes` table gains that column at the end. Strict JSON decoders and fixed-width `SELECT *` unpacking need updating. Existing columns retain their names and order; select named columns. True means the source explicitly blocks both elision and liaison. False means no lexical block is marked, rather than a guarantee that liaison occurs in every context.
- **Keep `h_aspire` specific to h:** its values remain unchanged from v0.4.0. Use the new flag for the explicitly marked non-h exceptions `ululer` and `yoyoter`.
- **Corrected data and delimiters:** alternatives use `;` without adjacent spaces; person-key delimiters remain unchanged. Source-authorized alternatives and missing participle slots are now present, malformed alternatives are corrected, and the erroneous `sur-aller` alternative under `aller` is removed. Consumers should split accepted alternatives rather than compare the entire value as one form.

This is a pre-1.0 minor release with a data-contract break. No verb entry is added or removed relative to v0.4.0. All 6,358 verb IDs and finite mood–tense/person coverage are preserved.

### Parser and source corrections

- Materialize explicitly source-authorized 1990 lexical î/û alternatives, including participles and reflexive/compound forms, while retaining grammatical circumflexes.
- Preserve alternatives for `absoudre`, `dissoudre`, `mouvoir` and repeat full auxiliary prefixes in compound participles and imperatives.
- Parse partial plural lists by gender/number. Apply narrow, exact-source corrections for the seven incomplete participle lists of `croître`, `recroître`, `devoir`, `redevoir`, including spelling aliases. Restore singular forms with traditional accents: `crû/crue`, `recrû/recrue`, `dû/due`, `redû/redue`.
- Preserve the explicitly invariant simple past participles `entre-nui` and `entrenui`.
- Repair `giter`/`gîter` spelling-variant links after homonym merging.
- Export the source's elision/liaison blocking marker independently of the initial letter.
- Exclude both `sur-aller` and `suraller` from infinitive generation/input/output, and remove only the exact erroneous alternative from `aller`: `allons ou sur-aller` → `allons`, and `nous en allons ou sur-aller` → `nous en allons`.
- Add `--reparse-cache` for offline reparsing. It bypasses the parsed store, keeps HTML unchanged, and refuses artifact generation if an input cache is missing or parsing fails. Existing parsed caches must be rebuilt when applying these parser changes.
